# Contribuindo para o MedCare-CLI

Olá! Agradeço seu interesse em contribuir com o projeto MedCare-CLI. Este é um projeto desenvolvido como parte dos meus estudos em Análise e Desenvolvimento de Sistemas, e qualquer contribuição para melhorá-lo é muito bem-vinda.

## Como Contribuir

Se você encontrou um bug, tem uma sugestão de melhoria ou gostaria de adicionar uma nova funcionalidade, por favor, siga estas etapas:

1.  **Reporte Bugs:** Abra uma [Issue](https://github.com/NelsonRibeiroFelix/medcare-cli/issues) detalhando o problema encontrado e os passos para reproduzi-lo.
2.  **Sugira Melhorias:** Para novas ideias ou funcionalidades, crie uma [Issue](https://github.com/NelsonRibeiroFelix/medcare-cli/issues) para que possamos discutir a proposta.
3.  **Envie Pull Requests (PRs):**
    *   Faça um *fork* deste repositório.
    *   Crie uma nova *branch* para sua contribuição (ex: `feature/nova-funcionalidade` ou `bugfix/correcao-x`).
    *   Implemente suas alterações, garantindo que o código siga os padrões estabelecidos.
    *   Certifique-se de que todos os testes existentes continuam passando (`pytest`) e, se aplicável, adicione novos testes para sua funcionalidade ou correção.
    *   Verifique a qualidade do código com o `ruff` (`ruff check .` e `ruff format .`).
    *   Faça o *commit* de suas mudanças com mensagens claras e descritivas.
    *   Abra um *Pull Request* para a branch `main` deste repositório, descrevendo suas alterações.

## Padrões de Código

Para manter a consistência e a qualidade do projeto, peço que as contribuições sigam:

-   As recomendações da [PEP 8](https://www.python.org/dev/peps/pep-0008/) para estilo de código Python.
-   Utilização do `ruff` para linting e formatação automática.
-   Novas funcionalidades devem ser acompanhadas de testes automatizados relevantes.

Sua colaboração é fundamental para o crescimento e aprimoramento do MedCare-CLI! Muito obrigado!
